# Code of Conduct

Stamp Loupe welcomes collectors, developers and newcomers of every background and level of experience. We want this project to be a respectful place to learn and work.

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository, in issues and pull requests, and in any space where you represent the project.

In short: be kind, assume good faith, and keep criticism about the work, not the person. Harassment, insults and sharing other people's private information are not accepted. That includes details of someone's collection, its location or its value.

## Reporting

If you see or experience something that breaks this code, tell the maintainers privately:

- Open a private report through the repository's Security tab ("Report a vulnerability"), and say it is a conduct report, or
- Email the address listed on the maintainer's GitHub profile.

Maintainers: replace the contact options above with a dedicated address before you announce the project.

Reports are handled in confidence. The enforcement guidelines in the Contributor Covenant describe the steps maintainers may take.
